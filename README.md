## 1. Лабораторийн ажлын зорилго

Энэхүү лабораторийн ажлын зорилго нь Exploratory Testing болон Session-Based Test Management (SBTM) аргыг ашиглан веб аппликейшний ажиллагааг судлах, согог илрүүлэх, туршилтын явцыг баримтжуулахад оршино.

Туршилтын хүрээнд хэрэглэгчийн интерфэйс, ном нэмэх, хайх, устгах үйлдэл, өгөгдлийн баталгаажуулалт болон API-ийн хариу үйлдлийг шалгасан.

## 2. Туршилтын хамрах хүрээ

Туршилтад дараах аяллуудыг ашигласан.

- **Couch Potato:** Хоосон, дутуу, буруу болон хязгаарын утгатай оролтуудыг шалгах.
- **Supermodel:** Хэрэглэгчийн интерфэйс, хайлт, товч, мессеж болон хүснэгтийн харагдах байдлыг шалгах.
- **Saboteur:** API-д буруу JSON болон шаардлага хангахгүй хүсэлт илгээж хариу үйлдлийг шалгах.
- **Fed-Ex:** Ном нэмэх, устгах болон жагсаалт, тоолуурын өгөгдлийн уялдааг шалгах.

## 3. Ашигласан хэрэгсэл

## 4. Туршилтын гүйцэтгэл

Туршилтын явцад ном нэмэх формын баталгаажуулалт, оны утгын хязгаар, давхардсан ном, хайлтын үсгийн том жижиг ялгаа, устгах товчны харагдах байдал, хайлтын дараах мессеж болон API-ийн буруу оролттой хүсэлтийн хариуг шалгасан.

Нийт 9 согогийн тайлан бэлтгэсэн. Тайлан бүрд дахин гаргах алхам, хүлээгдэж байсан үр дүн, бодит үр дүн, ноцтой байдал болон боломжтой нотлох баримтыг тусгасан.

## 5. Туршилтын үр дүн

Илэрсэн асуудлууд нь дараах үндсэн төрлүүдэд хамаарч байна:

- Оролтын утгын баталгаажуулалт.
- Өгөгдлийн бүрэн бүтэн байдал.
- Хайлтын ажиллагаа.
- Хэрэглэгчид үзүүлэх мессеж.
- Интерфэйсийн харагдах байдал.
- API-ийн хүсэлт баталгаажуулалт.

Дэлгэрэнгүй тайланг `bugs/` хавтаснаас, API хүсэлтийн нотолгоог `evidence/` хавтаснаас үзнэ үү.

## 7. Section E — Debrief

Миний хувьд Couch Potato аялал хамгийн үр дүнтэй байсан. Учир нь хоосон болон буруу утга оруулах үед системийн өгөгдөл баталгаажуулалттай холбоотой доголдлууд илэрсэн. Supermodel аяллын үеэр хайлтын үсгийн том, жижиг ялгаа, товчны өнгө болон хэрэглэгчид харагдах мессежийг шалгасан. Saboteur аяллаар буруу JSON болон шаардлага хангахгүй өгөгдлийг API руу илгээж, серверийн HTTP статус болон хариу body-г шалгасан. Fed-Ex аяллын үеэр жагсаалтад харагдах номын тоо болон нийт номын тоолуурыг харьцуулсан. Charter-аас гадуур нэмэлтээр шалгах шаардлагатай чиглэлүүдэд олон урт тексттэй номын хүснэгтийн харагдац болон линкүүдийн ажиллагаа орно. Playwright автомат тестээр хоосон талбарын баталгаажуулалт, хайлт, ном нэмэх болон тоолуурын утгыг шалгах боломжтой. Харин товчны өнгө, мессежийн ойлгомжтой байдал, интерфэйсийн харагдах байдлын зарим асуудлыг хүний ажиглалтаар илрүүлэх нь илүү тохиромжтой. Дараагийн session-д урт текст, бүх линк, хайлтын зохиогчийн нэр болон олон номтой үеийн хүснэгтийн ажиллагааг нарийвчлан шалгана.
